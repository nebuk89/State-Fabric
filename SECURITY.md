# Security Policy

State Fabric v0.1 is a public beta. Do not use it as the sole copy of critical
data or expose a node directly to an untrusted network.

## Reporting a vulnerability

Use GitHub private vulnerability reporting:

<https://github.com/nebuk89/cdn_git/security/advisories/new>

Do not open a public issue for suspected vulnerabilities involving credentials,
private object disclosure, signature verification, journal integrity, path
traversal, or acknowledged-state loss.

Include the affected version, platform, minimal reproduction, impact, and any
workaround. Avoid attaching real domain bundles, capabilities, keys, or private
workspace data.

## Supported versions

Only the latest v0.1 prerelease receives security fixes.
